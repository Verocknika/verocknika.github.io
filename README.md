# Veronika Portfolio

Personal portfolio website for presenting my projects, experience, technical skills and contact information.

The site is built as a lightweight static website and published through GitHub Pages:

https://verocknika.github.io

## Overview

This project started as a school assignment and was later developed into a personal portfolio. It combines a professional CV-style presentation with a more personal visual layer based on my own photography, hobbies and practical experience.

The website is available in two language versions:

- Slovak
- British English

## Main Features

- Responsive static website for desktop, tablet and mobile devices.
- Slovak and English page versions with a language switcher.
- Desktop navigation with stable button sizing.
- Mobile hamburger navigation with a compact language selector.
- Project cards with GitHub links and labels for private repositories.
- Contact form powered by Formspree.
- Privacy-friendly analytics with GoatCounter.
- Custom visual style, own photos and a small fox-themed brand element.

## Analytics

The website uses GoatCounter for privacy-friendly visitor analytics. It is used to track basic aggregated statistics such as page views and referrers without adding a heavy marketing analytics stack.

The GoatCounter snippet is included in all Slovak and English HTML pages.

## Local Development

This is a static website. No build step is required.

Recommended local workflow:

1. Clone the repository.
2. Open the folder in Visual Studio Code.
3. Use the Live Server extension or any static local server.
4. Open `index.html` in the browser.

## Testing Notes

The site has been checked manually across common viewport types, including desktop, ultra-wide desktop, tablet, touch-enabled laptop, mobile portrait and mobile landscape layouts. Particular attention was given to navigation behaviour, language switching, project cards and responsive layout stability.
